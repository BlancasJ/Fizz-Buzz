# Fizz-Buzz

React app that renders the classic FizzBuzz sequence from 1 to 100 with color-coded labels.

## Context
- **Course:** Ksquare University Bootcamp
- **Date:** 2021

## Tech Stack
- React 17
- Create React App
- CSS

## What It Does
Generates numbers 1 through 100 and applies FizzBuzz logic to each. Numbers divisible by 3 display "Fizz" in red, by 5 display "Buzz" in yellow, and by both display "Fizz Buzz" in green. All other numbers render as plain text.
